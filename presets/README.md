# Presets

Reusable render/style/platform presets belong here.

Suggested groups:

- `business/` — release/product visual systems;
- `2d/` — animation timing/line/palette presets;
- `3d/` — stylized lighting/cel/low-poly presets;
- `platforms/` — 9:16, 16:9, 1:1 export settings.

Presets should not contain mutable release facts or show canon.
