# Vision

## Mission

Build a reusable ChatGPT-driven video production system that can serve real business distribution and original entertainment production without confusing the two workflows.

## Lane A — Business / OSS release marketing

The goal is not generic promotional output. The goal is **truthful, version-specific marketing for useful released software**.

A viewer should be able to answer:

- What project/tool is this?
- Which version is the video describing?
- What does that release actually do?
- What changed from the prior release?
- Who is it useful for?
- Where can I get/use it?

The release version is part of the marketing identity, not hidden metadata.

## Lane B — Original animated productions

The goal is to create original scenes and eventually shows/episodes/seasons that can be published on social platforms and can support future monetization.

A show is treated as an IP/production system rather than a sequence of unrelated generated episodes. Season planning precedes episode rendering. Canon/continuity persists across episodes.

## Shared production values

- useful/entertaining final output over technical novelty;
- reproducible scene packages over one-off render scripts;
- actual rendered MP4 review over implementation claims;
- continuity and spatial correctness over approximate placement;
- version/canon truth over stale chat memory;
- original synthesis over copying existing shows.
